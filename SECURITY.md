# Security Policy

This repository should not contain secrets or private infrastructure details.

## Do Not Commit

- real `.env` files;
- private keys or SSH keys;
- API tokens;
- database dumps;
- backups;
- Terraform state;
- real IPs, customer names, customer domains or private hostnames.

## Reporting

Open a private security advisory or contact the repository owner if you find a
secret or private detail in the public repo. Rotate exposed credentials before
editing history.
