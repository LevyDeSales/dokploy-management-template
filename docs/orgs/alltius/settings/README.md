# Alltius Settings

Use this directory for org-level Dokploy settings and integrations that are shared across projects.

Do not store secret values.

## Files

- `git-sources.md`
- `registries.md`
- `ssh-keys.md`
- `certificates.md`
- `s3-destinations.md`
- `notifications.md`

Use `docs/templates/integration.md` when a setting needs a detailed file.
